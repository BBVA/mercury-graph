# EvidenceGraph Markdown examples

This small CC0 example corpus exercises the Markdown source entities used by
EvidenceGraph and contains simple, repeated facts for entity and relation
extraction.

Start with `robotics_club.md`. It uses headers 1 through 6, prose paragraphs,
links, an image, ordered and unordered lists, a table, a fenced code block, a
blockquote, a thematic break, and a footnote.
