# Tools in mercury.graph.evidence.formats

## Intention

In order to provide a framework that can seriously (i.e., handle a wikipedia dump with 25 million pages) manage sources, we need many
tools. The tools in this sub-sub-module are PoC implementations that allow us to build on top of the whole idea.

## Warning:

**These implementations are vibe-coded**. Ideally, if enough people want to build a community around this, we will have owners of different
parts and make these tools as good as they should be. For now, they are just a starting point pushing the problem of file conversion
to a precise place while still providing something that works well enough to be used as a PoC.
